## 脚本结构公式

### 通用结构
```
开场(3秒) → 发现(10秒) → 体验(20秒) → 总结(10秒) → 互动(5秒) → 结尾(5秒)
```

### 每部分要点

**开场（黄金3秒）**
- 抛出问题或悬念
- 制造好奇心
- 点明主题

**发现（铺垫）**
- 展示环境/背景
- 降低预期
- 为高潮做铺垫

**体验（核心）**
- 重点内容展示
- 突出亮点
- 真实感受表达

**总结（强化）**
- 强调核心卖点
- 给出评价
- 行动指引

**互动（引导）**
- 提出问题
- 引导评论
- 增加粘性

**结尾（收尾）**
- 总结回顾
- 关注引导
- 下期预告

## 拍摄技巧提示

### 镜头运用
- **近景**：食物特写、表情展示
- **中景**：体验过程、环境展示
- **全景**：环境全貌、氛围展示
- **特写**：价格标签、细节展示

### 运镜建议
- **推镜头**：引导注意力
- **拉镜头**：交代环境
- **摇镜头**：展示全貌
- **跟镜头**：增加动感

### 光线选择
- **自然光**：明亮、真实
- **暖色调**：增加食欲
- **逆光**：增加氛围感
